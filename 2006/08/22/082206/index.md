# 08/22/06

Today’s lessons are extentions of [yesterday](http://bhwilkoff.edublogs.org/2006/08/21/082106/).

Core 1-2:

- Discuss-On: What is the biggest book/reading virus (meme) you have ever started?
- Collect Book Meme.
- Re-introduce the [Discovery Bookshelf](http://discoverybookshelf.ning.com/) and go over [how to write a book review](http://www.thinkfree.com/filelink.tfo?filemasterno=368255&filekey=6lvglqfzlp).
- Show [How-To page](http://discovery0607.wikispaces.com/How+To) and go through [setting up Ning.com accounts](http://discovery0607.wikispaces.com/How+To#ning).
- Explore Ning.com
- Re-introduce the [Discovery Web Review](http://discoverywebreview.crispynews.com/) and go over [how to write a web review](http://www.thinkfree.com/filelink.tfo?filemasterno=368252&filekey=laldkuqo05).
- Introduce the [Password Manager](http://www.thinkfree.com/filelink.tfo?filemasterno=379581&filekey=3imz1anwa2) for your server folder.

Core 3:

- Go immediately to the Library for book checkout (Use round tables).
- Collect Book Meme
- Re-introduce the [Discovery Bookshelf](http://discoverybookshelf.ning.com/) and go over [how to write a book review](http://www.thinkfree.com/filelink.tfo?filemasterno=368255&filekey=6lvglqfzlp).
- Show [How-To page](http://discovery0607.wikispaces.com/How+To) and go through [setting up Ning.com accounts](http://discovery0607.wikispaces.com/How+To#ning).
- Explore Ning.com
- Introduce the [Password Manager](http://www.thinkfree.com/filelink.tfo?filemasterno=379581&filekey=3imz1anwa2) for your server folder.

Core 4:

- Check syllabus signatures.
- Use the [one book](http://faith-theology.blogspot.com/2006/07/one-book-meme.html) [meme](http://www.memecentral.com/) to start a dialog about books, createing a community of readers. [My example](http://yongesonne.edublogs.org/2006/08/21/not-tagged-the-book-meme/).
- Set library expectations.
- Travel to the library, use computers or the bookshelves to find the “next books” from your notecards.
- Read.
