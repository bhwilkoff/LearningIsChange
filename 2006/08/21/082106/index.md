# 08/21/06

Cores 1-2:

- Check syllabus signatures.
- Use the [one book](http://faith-theology.blogspot.com/2006/07/one-book-meme.html) [meme](http://www.memecentral.com/) to start a dialog about books, createing a community of readers. [My example](http://yongesonne.edublogs.org/2006/08/21/not-tagged-the-book-meme/).
- Review library expectations in order to keep our goals perfectly in view.
- Travel to the library, use computers or the bookshelves to find the “next books” from your notecards.
- Read.

Cores 3:

- Check Syllabus Signatures.
- Do [written version of Book Meme](http://www.thinkfree.com/filelink.tfo?filemasterno=378863&filekey=eh5l3o0qqn). [My Example](http://yongesonne.edublogs.org/2006/08/21/not-tagged-the-book-meme/). Check individualized goals on AR+ contracts and answer any questions.
- Set library expectations.
- Travel to the library, use computers or the bookshelves to find the “next books” from your notecards.
- Read.

Core 4:

- Show students how to find book recommendations, and pass out notecards for “next books.”
- Go to library and search on tower computers for “next books” and write down on notecards.
- Check-out and read books.
