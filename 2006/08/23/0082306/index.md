# 008/23/06

Much of today’s lessons are a continuation of [yesterday](http://bhwilkoff.edublogs.org/2006/08/22/082206/).

Core 1:

- Go over the process of actually submitting a book review.
- Discuss-On: How do you think that the [Discovery Bookshelf](http://discoverybookshelf.ning.com/) is going to help us to create a community of readers?
- Discuss-On: How do you think that creating web pages and content for those web pages changes the way we think about the internet?

- Re-introduce the [Discovery Web Review](http://discoverywebreview.crispynews.com/) and go over [how to write a web review](http://www.thinkfree.com/filelink.tfo?filemasterno=368252&filekey=laldkuqo05).
