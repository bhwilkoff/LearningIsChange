Alright, so Susan Spellman Cann has done an amazing job of inviting new folks to be members of the fellowship.

January 26, 2014 110 words · 1 min read by Ben Wilkoff

Alright, so Susan Spellman Cann has done an amazing job of inviting new folks to be members of the fellowship. I think it is time to move in to Open Spokes 2.0 with everyone on board!

To do this, I have drawn up a new planning document: https://docs.google.com/document/d/1BRQL7cI3Ry56IGWt8DdmkGiQz-lEkJF-jHJNI2L4eoM/edit?usp=docslist_api

Would each of you go in and put your info in for the type of role(s) you would like to have in this new iteration. Also, please invite any folks (directly) that you would like to take part. This is going to be great!

Let me know if you have any questions, but I will “see” all of you soon.
