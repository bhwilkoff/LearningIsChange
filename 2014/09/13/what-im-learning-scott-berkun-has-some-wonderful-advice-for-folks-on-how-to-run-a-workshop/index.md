# What I'm Learning: Scott Berkun has some wonderful advice for folks on how to run a workshop.

I absolutely love these rules and the ideas behind them. Study this blog post!

[How to run a good workshop](http://scottberkun.com/2013/run-a-good-workshop/)

> - RULE #1: A 3 HOUR LECTURE IS NOT A WORKSHOP - RULE #2: THE MORE STUDENTS YOU HAVE, THE LESS OF A WORKSHOP IT IS - RULE #3: WORK THE TRIAD: EXPLAIN, EXERCISE, DEBRIEF - RULE #4: STAY OUT OF THE CENTER - RULE #5: BETA TEST YOUR EXERCISES - RULE #6: MATCH PROMISES TO EXERCISES - RULE #7: ALWAYS HAVE A WHITEBOARD OR FLIPCHART IN THE ROOM - RULE #8: THE ROOM SHOULD LOOK LIKE A WORKSHOP WHEN YOU ARE DONE - RULE #9: BUILD A WORKSHOP CHECKLIST - RULE #10: GIVE STUDENTS THE NEXT THING TO DO AFTER THEY LEAVE
