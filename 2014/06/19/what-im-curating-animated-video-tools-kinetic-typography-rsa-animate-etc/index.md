# 5 Animated Video Tools for creating Kinetic Typography (i.e., RSA Animate)

I have realized that there are a number of new tools to do animated video creation, and I wanted to start a running list. Please comment on this post if you have others that you are using:

- [http://www.moovly.com/](http://www.moovly.com/) – Some really sophisticated timeline editor tools.
- [http://www.powtoon.com/](http://www.powtoon.com/) – So many different options, and probably the most popular tool.
- [https://explee.com/](https://explee.com/) – Canvas-based tool that is extremely opened ended.
- [http://goanimate.com/](http://goanimate.com/) – Good tool, but there aren’t any free options.
- [http://wideo.co/](http://wideo.co/) – A rather new tool, but super easy and it connects with google drive.
