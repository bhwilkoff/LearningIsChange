# What I'm Using: Animated Gif Creation on the Chromebook

While it isn’t as good as [Licecap](http://www.cockos.com/licecap/) for Mac or PC, it is getting me closer to creating flipped PD documents using Gifs from wherever I am. Looking forward to using this all of the time on my Chromebook.

[Chrome Web Store – Animated Gif Capture](https://chrome.google.com/webstore/detail/animated-gif-capture/aecmckhhfknljgicfkpbinfkpnijehcm)

> Capture visible content of a tab, desktop screen, or selected application window as a animated GIF image. The Animated Gif Capture Chrome extension helps you convert screen capture to animated GIF image.
