# Project Roundtable: How Can Hangouts Transform Teacher Collaboration?

The planning doc: [http://bit.ly/hangoutroundtable](http://bit.ly/hangoutroundtable)

Hangout Purpose: The purpose of this roundtable is to explore all of the ways in which Google+ Hangouts can and will transform the collaborations happening synchronously and asynchronously between teachers and leaders around the world. While this tool has only been around for a few years, it is clear that it has made huge inroads into both professional development and peer-to-peer learning. This roundtable will lay out effective practices and dig into what makes this tool such an essential one for our schools and districts.

Hangout Audience:This roundtable is for any teacher or leader who is either currently using or considering using Google+ hangouts as a way to increase teacher collaboration within a school, across a district, or around the world.
