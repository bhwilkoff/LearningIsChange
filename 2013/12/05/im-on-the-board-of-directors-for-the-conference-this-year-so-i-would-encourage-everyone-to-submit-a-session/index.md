# I’m on the Board of Directors for the conference this year, so I would encourage everyone to submit a session…

I’m on the Board of Directors for the conference this year, so I would encourage everyone to submit a session (because it is going to be awesome!):

Deadline for the 2014 InnEdCo Conference Presentation applications has been extended to Friday, December 13th, 5:00pm. The theme for the conference is Inspiring Digital Age Teaching and Learning. We invite educators, school/district/state leaders, educational technology as well as technical support colleagues to apply to present!
