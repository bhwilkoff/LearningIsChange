# There is a pretty amazing discussion going on around “Girls on Youtube”, and if you aren’t following along, please…

There is a pretty amazing discussion going on around “Girls on Youtube”, and if you aren’t following along, please take this opportunity to do so. It is the kind of discussion that we are missing many times in our educational discourse.

I have done a video response for it ([http://youtu.be/GDAqUqIqm14](http://youtu.be/GDAqUqIqm14)), but I’m including the original links which are much more important (the responses from the women below are really great).

There is no single community to rule them all. There is no single goal for learning. There is also no single monolithic community for Youtube. And, we shouldn’t pretend that there is.

What are you doing to highlight the voices around you and your own “pocket communities”?
