    1. Create a copy of the template with tags

    2. Read line 1 from sheet

    3. replace tags

    4. Repeat 1-3 with next line

    Append steps

    1. Create a copy of the template with tags

    2. Read line 1 from sheet

    3. replace tags

    4. Append to doc created in step 1.

    5. Read next line

    6. Replace Tags

    7. Repeat 4-6
