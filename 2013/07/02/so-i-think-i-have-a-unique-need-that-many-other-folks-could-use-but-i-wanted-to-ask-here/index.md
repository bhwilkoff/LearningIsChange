# So, I think I have a unique need that many other folks could use, but I wanted to ask here.

So, I think I have a unique need that many other folks could use, but I wanted to ask here.

I would love to be able to use a script similar to DocAppender to set multiple documents to be Appended to based upon a drop down set in each form submission.

The use case: If I wanted to do running records for for a whole bunch of different schools, but I wanted to append those notes to different notes files in different folders, could I set the document I want to append by choosing the school name from the drop down?

Andrew Stillman Any thoughts on this? Can I just extend DocAppender or would we need to do some additional development?
