**Make Phone Calls using the Hangouts Sidebar**

Now we can make **Video calls**, or **Phone calls** using the Hangout Sidebar… here is the full info: [http://goo.gl/eRco4](http://goo.gl/eRco4)

We were able to make phone calls from within a hangout invite dialog box for a little while now, or receive phone calls inside a hangout as well, but now we can do what many people have been missing: **Initiate a Phone Call from the Hangout Sidebar interface.**

Open up the Sidebar via the Green Hangouts symbol, then choose the Drop-down options… below the Snooze notifications area, we can also choose to initiate a phone call (like the ‘days of old’ with Google Voice).

Happy days are ‘hear’ again for those that want to use Google to make phone calls!
