# Hey, all.

Hey, all. I just wanted to let you know that I have set up a Google Drive folders for sharing resources across all schools that are doing some form of blended learning in the coming school year. The George Washington folder is here: [https://drive.google.com/folderview?id=0ByXFNpMMmaw3R1Z3R1pQT3NNTDg&usp=sharing](https://drive.google.com/folderview?id=0ByXFNpMMmaw3R1Z3R1pQT3NNTDg&usp=sharing)

If you share anything inside of the “Resources” folder it will automatically be shared with the other schools. So please share generously, but don’t remove things because they will be removed for everyone. Let me know if this doesn’t make sense, though.
