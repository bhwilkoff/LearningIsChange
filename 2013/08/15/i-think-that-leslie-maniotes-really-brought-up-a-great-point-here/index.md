# I think that Leslie Maniotes really brought up a great point here.

I think that Leslie Maniotes really brought up a great point here.  In sharing this document, she is asking the question about what the shared space should be for all of the files and folders you will be creating and using. While I would recommend building out folders within the [http://bit.ly/dpsnetworks](http://bit.ly/dpsnetworks) structure, I think that you all have the ability to create and define the space that you want to play within.
