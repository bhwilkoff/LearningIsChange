Core 4:

- Now that we have gotten far enough into this project to tell really what it is all about, we need to decide what the end goal is for each of us.  How is this “writing” assignment different than a traditional writing assignment, and how does that influence the way in which we should grade it?

- What would you look for in a “good utopia?”
- What should the requirements be?

- Answer the Personalized Discussion Questions and work on your Utopia.
