Archive Watch

iOS iPadOS tvOS macOS Android Web

A cinematheque for the public domain. Archive Watch turns the Internet Archive's ~37,000 public-domain films, classic TV, silent cinema, animation, and vintage commercials into a beautiful, curated, ad-free viewing experience — on your phone, tablet, TV, Mac, and browser.

It's the fullest expression of how I build: a single SQLite catalog published over HTTP (queried in place by the web, downloaded and inflated by native clients), a resilient streaming layer that survives flaky origins, deterministic "Live Channels" that play the same on every device, CloudKit sync across Apple hardware, and a self-healing content pipeline running entirely on GitHub Actions — no backend to pay for.

The principles behind the templates

Feature parity, not design consistency. Every app does the same things on every platform, but expresses them in each platform's native idiom — a SwiftUI .sheet, a Compose bottom sheet, a native web <dialog>, a tvOS focus picker. A single-source-of-truth parity matrix, audited against the real code, keeps every platform honest.

No servers, no paid tiers. Sync rides on each ecosystem's own cloud — CloudKit for Apple, the user's Drive or AT Protocol repo elsewhere. Data ships as static files. Everything deploys through free GitHub Actions, including the cloud-CI App Store and Play Store submission pipelines.

The through line
