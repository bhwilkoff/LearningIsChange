Career

Education Leadership

I started in a middle school English classroom. Since then I have led blended learning for two districts, run a VR/AR program for a dental school, and now run admissions operations for a university. Every one of those jobs was the same job: help people learn.

Native Apps, Built End to End

I design, build, and ship native apps by myself, from the first sketch to store review. Each one is a single shared core with a native shell for every screen it lives on. I want the same app on a phone, a TV, and a desktop, with no server behind it to pay for or to fail.
