# I collected all of the learning space tours that have already been shared within this community into a single…

I collected all of the learning space tours that have already been shared within this community into a single collection. I’m so inspired by seeing all of these spaces around our district. They make me think about two questions: What can you learn from these spaces? What does your space look like in relationship to these?
