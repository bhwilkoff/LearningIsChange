# I have been wanting a way to attach files to emails on the iPad for a very long time.

I have been wanting a way to attach files to emails on the iPad for a very long time. Fileboard (just released today) finally gets me there, so long as my files are stored on Dropbox, that is (but pretty much all of them are, so that’s good).
