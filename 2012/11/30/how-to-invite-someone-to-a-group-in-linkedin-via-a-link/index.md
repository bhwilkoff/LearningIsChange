# How to invite someone to a group in LinkedIn via a link

If you want to invite someone to a LinkedIn group without having to be connected to them first, you can use the following URL to get it done:

[http://www.linkedin.com/manageGroup?dispAddMbrs=&gid=941557&invtActn=im-invite&cntactSrc=cs-connections&trk=grpmgr_invite](http://www.linkedin.com/manageGroup?dispAddMbrs=&gid=941557&invtActn=im-invite&cntactSrc=cs-connections&trk=grpmgr_invite)

Change the gid # to the group ID number that is in the URL of your favorite group. Simply type in their email addresses.
