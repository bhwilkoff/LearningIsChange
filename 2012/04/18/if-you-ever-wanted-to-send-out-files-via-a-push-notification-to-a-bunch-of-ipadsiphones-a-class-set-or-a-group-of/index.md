# If you ever wanted to send out files via a push notification to a bunch of iPads/iPhones (a class set or a group of…

If you ever wanted to send out files via a push notification to a bunch of iPads/iPhones (a class set or a group of team members, perhaps) you can simply download the iMessages beta from the link below and then drag and drop as many files as you want to into it to send a message. Just put all of your team members (or students, or whatever) into the recipients line.

It even sends those files to yourself because it will show up in the conversation on your iPad/iPhone.

As another idea, if you set up a second Apple ID, you can send yourself messages and files without ever having to login to that secondary ID. It will just show up in your conversation with that other ID on your phone/ipad.

http://www.apple.com/macosx/mountain-lion/messages-beta/
