ℹ️ How This Works

This tool scans your GitHub Pages repository, extracts metadata from all HTML files (posts, pages, archives), and generates a JSON database plus a SQLite file for client-side search. Posts are detected by their URL pattern (YYYY/MM/DD/slug/) and HTML classes. Categories and tags are extracted from article classes and page links.

About This Tool

                
The Database Generator creates a file-based database from your static GitHub Pages site, enabling features like search that typically require a dynamic server.

                
Rate Limits: GitHub allows 5,000 API requests/hour. Large repos may require multiple sessions with automatic pause/resume.
