📚 Database Maintenance

GitHub PAT

What this does

Recomputes counts and indexes from database/posts/YYYY.json + database/pages.json. Useful after bulk operations (dedup, post removals, mass updates) leave the database stats stale.

📊 database/manifest.json — total_posts, total_categories, total_tags, date_range, per-shard counts
🏷 database/taxonomies.json — per-category and per-tag counts (removes unused entries)
🔍 database/search.json — rebuilt from current posts; powers site search
Source-of-truth files (posts/YYYY.json, pages.json) are read but not modified. Append-only files (changelog.json) are left alone. search.db (SQLite FTS) needs a separate tool.
