How this works

  1. Edit a fragment in templates/fragments/<zone>.html locally or via GitHub's web editor.
  2. Commit the fragment change to main.
  3. Come here, pick the zones you changed, and Dispatch.
  4. The regenerate-fragments.yml workflow walks every HTML page, replaces the content between LIC:<ZONE>:START/:END markers with the fragment, commits the result.

Pages without markers (e.g. admin tools) are skipped automatically. The operation is idempotent — running twice on an unchanged fragment is a no-op.
